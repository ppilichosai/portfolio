# Panagiotis Pilichos: bilingual portfolio (EN "/" and EL "/el")
Next.js 15, TypeScript, Tailwind CSS 3. No analytics, no tracking, no paid services.

    npm install
    npm run dev      # http://localhost:3000 and /el
    npm run build

Edit text in `content/en.ts` and `content/el.ts` (same keys), shared facts in `content/site.ts`.
Set `NEXT_PUBLIC_SITE_URL` in Vercel (see `.env.example`).
